C++의 뼈대: 기초 문법

첫 번째 프로그램: Hello World 분석하기

C++ 여정의 첫걸음은 언제나 그렇듯 "Hello World"를 화면에 띄우는 것입니다. 코드는 짧아 보이지만, 이 안에는 C++ 프로그램이 어떻게 구성되고 실행되는지에 대한 핵심 원리가 숨어 있습니다. 우리는 단순히 타자를 치는 것을 넘어, 각 줄이 컴파일러에게 어떤 명령을 내리는지 정확히 이해해야 합니다.

C++은 컴파일 언어입니다. 우리가 작성한 소스 코드(사람이 읽을 수 있는 텍스트)를 기계어(컴퓨터가 이해하는 0과 1)로 변환하는 '컴파일' 과정이 필수적입니다. 이 코드는 그 컴파일러에게 전달하는 가장 기본적인 편지입니다.

// iostream 헤더 파일을 포함합니다. Input/Output Stream의 약자로, 입출력 기능을 제공합니다.
#include <iostream>

// 프로그램의 진입점(Entry Point)입니다. 운영체제가 이 프로그램을 실행할 때 가장 먼저 찾는 함수입니다.
int main() {
    // std 네임스페이스 안에 있는 cout 객체를 사용하여 화면에 문자열을 출력합니다.
    // '<<' 연산자는 데이터의 흐름을 나타내며, 문자열을 cout(콘솔 출력)으로 보냅니다.
    std::cout << "Hello, C++ World!" << std::endl;

    // 프로그램이 성공적으로 종료되었음을 운영체제에게 알립니다. 0은 '정상 종료'를 의미합니다.
    return 0;
}

핵심 개념 파헤치기

  • #include: 이것은 전처리 지시자(Preprocessor Directive)입니다. 컴파일이 시작되기 전에, <iostream>이라는 표준 라이브러리 파일의 내용을 현재 파일에 복사해 넣으라는 지시입니다. 요리를 하기 전에 필요한 레시피 북을 가져오는 것과 같습니다.
  • main() 함수: 모든 C++ 프로그램은 반드시 단 하나의 main 함수를 가져야 합니다. 아무리 거대한 게임이나 시스템이라도, 실행의 시작은 항상 이 함수부터입니다.
  • std::cout과 std::endl: std는 'Standard(표준)'을 의미하는 네임스페이스(이름 공간)입니다. 이름이 겹치는 것을 방지하기 위한 성씨와 같습니다. cout은 콘솔 출력(Console Out)을, endl은 줄바꿈(End Line) 및 버퍼 비우기를 수행합니다.

메모리 지배의 시작: 변수와 자료형

프로그래밍이란 결국 데이터를 처리하는 과정입니다. 데이터를 처리하려면 그 데이터를 잠시 보관해 둘 공간이 필요한데, 그것이 바로 컴퓨터의 메모리(RAM)입니다. 변수(Variable)는 이 메모리 공간에 우리가 붙여준 '이름표'입니다.

C++은 매우 엄격한 정적 타입 언어(Statically Typed Language)입니다. 변수를 만들기 전에 반드시 "이 공간에는 어떤 종류의 데이터를, 얼만큼의 크기로 저장할 것인가?"를 명시해야 합니다. 이것이 바로 자료형(Data Type)입니다. 파이썬이나 자바스크립트와 달리, C++은 메모리를 한 치의 오차도 없이 효율적으로 쓰기 위해 이러한 엄격함을 요구합니다.

#include <iostream>
#include <string> // 문자열을 다루기 위한 헤더

int main() {
    // 1. 정수형 (Integer): 소수점이 없는 숫자. 보통 4바이트 크기입니다.
    int level = 99;

    // 2. 실수형 (Floating-point): 소수점이 있는 숫자. double은 정밀도가 높은(8바이트) 실수입니다.
    double health = 100.5;

    // 3. 문자형 (Character): 단 하나의 문자. 작은따옴표('')를 사용합니다. 1바이트 크기.
    char rank = 'S';

    // 4. 논리형 (Boolean): 참(true) 또는 거짓(false) 두 가지 상태만 가집니다. 조건문에 필수적입니다.
    bool isGameOver = false;

    // 5. 문자열 (String): 문자의 나열. 큰따옴표("")를 사용합니다. 기본 자료형이 아닌 표준 라이브러리 클래스입니다.
    std::string playerName = "지훈";

    // 변수들을 조합하여 하나의 문장으로 출력합니다.
    std::cout << "플레이어 " << playerName << "님의 레벨은 " << level << "입니다." << std::endl;

    return 0;
}

Tip: C++에서 타입 선언은 메모리 할당의 설계도입니다. int level;이라고 쓰는 순간, 컴파일러는 메모리에 4바이트의 공간을 확보하고, 앞으로 그 공간을 'level'이라고 부르기로 약속하는 것입니다. 성능이 중요한 C++에서는 데이터의 성격에 맞는 최소한의 자료형을 선택하는 것이 중요합니다.

세상을 모델링하다: 객체 지향 (OOP)

클래스(Class)와 객체(Object), 그리고 캡슐화

프로그램이 커지면 수많은 변수와 함수들이 뒤섞여 관리하기가 매우 힘들어집니다. 객체 지향 프로그래밍(Object-Oriented Programming)은 이 문제를 해결하기 위해 등장한 패러다임입니다. 현실 세계의 사물(Object)처럼, 관련된 '상태(데이터, 변수)'와 '행동(기능, 함수)'을 하나의 묶음으로 설계하는 방식입니다.

이 묶음의 설계도가 바로 클래스(Class)입니다. 붕어빵 틀과 같죠. 그리고 이 설계도를 바탕으로 메모리상에 실제로 생성된 결과물이 객체(Object), 즉 붕어빵입니다. C++은 C언어에 이 강력한 클래스 개념을 더하면서 시작되었습니다.

특히 주목해야 할 것은 접근 제어자(public, private)를 통한 캡슐화(Encapsulation)입니다. 중요한 데이터는 외부에서 함부로 건드리지 못하게 꽁꽁 숨기고(private), 오직 정해진 방법(public 메서드)을 통해서만 조작하도록 하여 프로그램의 안정성을 극대화합니다.

#include <iostream>
#include <string>

// 'Car(자동차)'라는 새로운 데이터 타입을 설계합니다.
class Car {
private:
    // 캡슐화: 외부에서 속도나 브랜드를 맘대로 바꾸면 위험하므로 숨깁니다 (Data Hiding).
    std::string brand;
    int speed;

public:
    // 생성자 (Constructor): 객체가 생성될 때 단 한 번, 자동으로 호출되는 특별한 함수입니다.
    // 주로 멤버 변수를 초기화하는 역할을 담당합니다.
    Car(std::string b) {
        brand = b;
        speed = 0; // 처음 차가 만들어졌을 때 속도는 당연히 0입니다.
        std::cout << brand << " 차량이 생산되었습니다." << std::endl;
    }

    // 멤버 함수 (Method): 객체가 할 수 있는 행동(기능)을 정의합니다.
    // 외부에서는 오직 이 함수를 통해서만 숨겨진 speed 변수에 영향을 줄 수 있습니다.
    void accelerate(int amount) {
        if (amount < 0) {
            std::cout << "경고: 가속 값은 음수가 될 수 없습니다!\n";
            return;
        }
        speed += amount;
        std::cout << brand << " 가속 중! 현재 속도: " << speed << "km/h\n";
    }

}; // 클래스 선언 끝에는 반드시 세미콜론(;)이 필요합니다.

int main() {
    // Car 설계도를 바탕으로 'myCar'라는 실제 객체(인스턴스)를 메모리에 생성합니다.
    // 이때 "Tesla"라는 값이 생성자로 전달됩니다.
    Car myCar("Tesla");

    // myCar.speed = 100; // 에러! private 변수에는 직접 접근할 수 없습니다.

    // public으로 열려있는 가속 페달(메서드)을 밟아 간접적으로 속도를 올립니다.
    myCar.accelerate(30);
    myCar.accelerate(20);

    return 0;
}

모던 C++의 우아함: 고급 주제

메모리 누수와의 전쟁 종결: 스마트 포인터

C++이 어렵기로 악명 높은 이유 중 하나는 프로그래머가 메모리 할당(new)과 해제(delete)를 직접 관리해야 하는 수동 메모리 관리 때문입니다. 실수로 delete를 잊어버리면 메모리 공간이 영원히 반환되지 않는 메모리 누수(Memory Leak)가 발생하여 프로그램이 뻗어버릴 수 있습니다.

C++11부터 도입된 스마트 포인터(Smart Pointer)는 이 문제를 혁명적으로 해결했습니다. 객체의 소유권이라는 개념을 도입하여, 포인터가 사용되는 범위(Scope)를 벗어나는 순간 알아서 메모리를 해제해 줍니다. 이제 우리는 new와 delete의 짝을 맞추는 강박에서 벗어나, 로직 그 자체에 집중할 수 있게 되었습니다.

과거의 방식: 원시 포인터 (Raw Pointer)

직접 메모리를 빌려오고, 직접 갚아야 합니다. 중간에 에러가 나서 delete를 건너뛰면 대참사가 일어납니다.

int* ptr = new int(10);
// 중간에 예외(Error)가 발생한다면?
// 아래 코드는 영원히 실행되지 않습니다!
delete ptr; // 메모리 누수 발생!

모던 C++: 스마트 포인터 (Smart Pointer)

std::unique_ptr는 메모리의 독점적 소유권을 가집니다. 자기가 죽을 때 자원도 같이 묻어버립니다.

#include <memory>
// make_unique로 안전하게 생성합니다.
std::unique_ptr<int> ptr =
    std::make_unique<int>(10);
// delete를 쓸 필요가 없습니다! 자동 소멸.
#include <iostream>
#include <memory> // 스마트 포인터를 사용하기 위한 필수 헤더

class DatabaseConnection {
public:
    DatabaseConnection() { std::cout << "DB 연결 설정됨 (자원 획득)\n"; }
    ~DatabaseConnection() { std::cout << "DB 연결 해제됨 (자원 자동 반납!)\n"; }
    void query() { std::cout << "데이터 조회 중...\n"; }
};

int main() {
    std::cout << "--- 특정 함수/블록 시작 ---\n";
    {
        // make_unique를 통해 안전하게 객체를 생성하고 포인터를 만듭니다.
        // 이 'db' 포인터는 이 중괄호 블록 { } 안에서만 유효합니다.
        std::unique_ptr<DatabaseConnection> db = std::make_unique<DatabaseConnection>();

        db->query(); // 기존 포인터처럼 화살표(->) 연산자로 사용합니다.

    } // ★ 중요: 블록이 끝나는 이 지점에서 db 포인터가 파괴되며, 연결된 객체의 소멸자(~)가 자동으로 호출됩니다!
    std::cout << "--- 특정 함수/블록 종료 ---\n";

    return 0;
}

마법의 도구 상자: STL (표준 템플릿 라이브러리)

프로그래밍을 하다 보면 데이터를 저장하고 관리하기 위한 구조(자료구조)와 데이터를 정렬하거나 검색하는 방법(알고리즘)이 반복적으로 필요합니다. 이것들을 매번 밑바닥부터 새로 짜는 것은 엄청난 시간 낭비입니다.

C++은 STL(Standard Template Library)이라는 매우 강력하고 최적화된 도구 상자를 기본으로 제공합니다. 우리는 필요할 때 이 상자를 열어 이미 완성된 고성능의 도구들을 꺼내 쓰기만 하면 됩니다. 대표적으로 동적 배열인 std::vector, 정렬을 해주는 std::sort 알고리즘 등이 있습니다. STL을 잘 다루는 것이 C++ 실력의 척도라고 해도 과언이 아닙니다.

#include <iostream>
#include <vector>    // 크기가 유동적으로 변하는 마법의 배열, vector 컨테이너
#include <algorithm> // 정렬, 검색 등 유용한 알고리즘 모음

int main() {
    // 1. 컨테이너 (Container): 데이터를 담는 그릇.
    // 기존의 고정 크기 배열과 달리, vector는 공간이 부족하면 스스로 크기를 늘립니다.
    std::vector<int> scores = {85, 72, 93, 64};

    // push_back() 메서드를 사용해 맨 뒤에 손쉽게 새 데이터를 추가할 수 있습니다.
    scores.push_back(99);

    std::cout << "정렬 전: ";
    // 모던 C++의 Range-based for 반복문. 컨테이너의 처음부터 끝까지 매우 간편하게 순회합니다.
    for (int s : scores) {
        std::cout << s << " ";
    }

    // 2. 알고리즘 (Algorithm): 데이터를 처리하는 로직.
    // std::sort를 호출하고, 시작점(begin)과 끝점(end)만 알려주면 초고속으로 정렬해 줍니다.
    std::sort(scores.begin(), scores.end());

    std::cout << "\n오름차순 정렬 후: ";
    // auto 키워드: C++11부터 도입. 컴파일러가 scores 안에 든 데이터가 int임을 알아서 '추론'합니다.
    for (auto s : scores) {
        std::cout << s << " ";
    }
    std::cout << std::endl;

    return 0;
}
